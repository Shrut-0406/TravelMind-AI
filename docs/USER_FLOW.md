# User Flow

## Step 1
User opens TravelMind AI

↓

## Step 2
User enters:

- Starting location
- Destination
- Trip duration
- Budget
- Interests
- Travel style

↓

## Step 3
AI processes:

- Route
- Attractions
- Weather
- Cost

↓

## Step 4
User receives:

- Daily itinerary
- Map
- Budget
- Recommendations

↓

## Step 5
User can modify the trip
